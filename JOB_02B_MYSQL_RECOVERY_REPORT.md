# JOB 02B MySQL Homebrew Recovery Report

## 1. Root Cause
- The original `.env` used `DB_HOST=localhost`. Homebrew MySQL on Apple Silicon provides only a TCP listener; the Unix socket does not exist, causing `2003 (HY000): Can't connect to MySQL server on 'localhost:3306'`.
- Changing to `DB_HOST=127.0.0.1` forces a TCP connection, resolving the connectivity error.
